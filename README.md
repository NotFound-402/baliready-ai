# Baliready AI

Aplikasi assessment dan rekomendasi roadmap berbasis AI.

## Struktur Proyek

- `app/` berisi konfigurasi, controller, model, dan service
- `public/` berisi entry point frontend dan asset publik
- `views/` berisi template halaman aplikasi
- `database/` berisi schema database

## Setup

1. Salin file `.env.example` menjadi `.env` jika diperlukan.
2. Konfigurasikan koneksi database pada `app/config/database.php`.
3. Import SQL dari `database/baliready.sql`.
4. Jalankan aplikasi melalui server web.
